Loop transformers, SDK deprecations, and batching cheap

A new coding model architecture, a dated Opus 4.5 retirement, and a reminder that non-urgent AI work should go through batch endpoints.

What shipped today

  1. GLM-5.4: Toward generalized coding with our first loop transformer

    GLM-5.4 is billed as a first loop transformer aimed at generalized coding, and it drew a lot of attention on Hacker News. If you pick coding models for your tools, it's worth watching how this architecture holds up on your own tasks.

  2. sdk-v1.13.0

    Anthropic TypeScript SDK 1.13.0 adds batch error codes and Admin API external storage, and marks Claude Opus 4.5 deprecated with end-of-life on Jan 22, 2027. If you depend on that model, put the migration on your calendar now.

  3. claude-code 2.1.331

    Claude Code 2.1.331 adds Code Mode in terminal sessions on Bedrock, Google Cloud, Foundry and AWS, plus a claude doctor API connectivity check. The doctor check is handy for debugging setup problems on cloud-hosted configurations.

  4. How to build and maintain an agentic evaluation

    Hugging Face published a guide on building and maintaining an agentic evaluation. Agents are hard to judge by eye, so a maintained eval is how you notice regressions when you change prompts or models.

  5. Finding faster quantum algorithms with agents and formal verification

    DeepMind pairs agent teams with formal verification to find improved quantum algorithms for fusion and chemistry. The useful pattern is having a verifier check what the agents propose rather than trusting their output.

Technique of the day

Batch API

Batch APIs let you submit many requests at once and collect results later instead of waiting on each one in real time. They suit work where nobody is waiting on the answer, such as classifying a backlog, summarizing documents, or running evals. The trade-off is latency for a lower cost per request, so the question to ask is whether a human needs the result right now.
