Looped transformers, tiny quantized models, and a plain API call

Today's news leans toward models that think in loops and fit in smaller files, plus a few tooling updates worth knowing about.

What shipped today

  1. GLM-5.4: Toward generalized coding with our first loop transformer

    GLM-5.4 is described as Zhipu's first loop transformer, aimed at generalized coding. If you pick coding models for your tools, it's worth watching how looped designs perform in practice.

  2. NariQ: BF16-level Qwen3.8-27B in a 10 GB file

    NariQ offers 3-bit and lower quantizations of Qwen3.8-27B in about 10 GB, and claims near-BF16 results on several benchmarks. If that holds up, a large model could run on much more modest hardware, but I'd test it on my own tasks first.

  3. sdk-v1.13.0

    Anthropic TypeScript SDK 1.13.0 adds Message Batches error codes and marks Claude Opus 4.5 deprecated, with end of life on Jan 22, 2027. If you call that model directly, put a migration on your calendar.

  4. Can Latent Reasoning Drive LLM Outputs Without a Trace?

    This study asks whether LLMs can do tasks through latent reasoning with no visible chain-of-thought. It matters because monitoring a model's written reasoning may not catch everything it does.

  5. openai/codex 0.172.0

    Codex 0.172.0 adds Tab completion for slash command arguments and optional stdio MCP servers. These are small changes, but they reduce friction in daily agent use.

Technique of the day

Direct LLM API call

A direct LLM API call means sending a request to a model provider from your own code, rather than going through a chat app or agent tool. You control the prompt, the model, the parameters, and what you do with the response. It's the base layer that most AI features are built on, and it makes the cost, errors, and behavior easy to see.

Try it

Write a small script that sends one request to a model API. Set the model name, a system prompt, and one user message. Then print the raw response, including the token usage fields. Run it three times with different prompts and compare the usage numbers. Keep your API key in an environment variable, not in the code.
