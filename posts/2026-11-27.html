Tighter OpenAI limits, Google's MCP push, and building your own MCP server

OpenAI reportedly trimmed usage allowances, Google wants agents to use its own MCP servers, and today is a good day to write a small server of your own.

What matters today

  1. OpenAI cuts GPT-6.2 usage: Astra hits limits 40% faster, Sol 25% faster

    OpenAI has reportedly cut how much GPT-6.2 you can use before hitting a limit. Astra plans run out about 40% faster and Sol plans about 25% faster. If your daily work leans on these plans, you may hit a wall sooner than you planned.

    Real-world example

    A freelance developer who usually codes all afternoon on a Sol plan could find the limit kicks in mid-session, right before a client deadline.

    How you could use it

    Check where your workflow depends on a single plan's allowance and keep a second tool or model ready to switch to. If you build apps on top of it, show clear messages when a limit is hit instead of failing silently. It is also a good moment to trim long prompts and repeated context so each session goes further.

  2. Google Will Make AI Agents Use Its MCP Servers. The Gmail One Can't Send Email

    Google plans to route AI agents through its own MCP servers. MCP, short for Model Context Protocol, is a standard way to plug tools and data into an AI assistant. Critics point out that Google's Gmail MCP server currently cannot send email, so check what these official servers actually do before you rely on them.

    Real-world example

    A small support team hoping an agent could draft and send replies from Gmail could find it can read the inbox but has to hand the actual sending back to a person.

    How you could use it

    Before building on an official MCP server, list the exact actions your app needs and confirm each one is supported. Where something is missing, plan a human step or a small custom server to fill the gap. Design your agent so a missing action leads to a clear 'needs your approval' step rather than a dead end.

  3. Building on Nemotron 3.5 Parse: Open Data, Fine-Tuning, and Faster Inference

    NVIDIA published open data, fine-tuning recipes and faster inference for Nemotron 3.5 Parse, its model for reading documents. Fine-tuning means training a model a bit more on your own examples so it handles your kind of documents better. Faster inference means it returns answers more quickly.

    Real-world example

    A clinic that receives scanned intake forms in several layouts could tune a document reader on its own forms so the fields come out in the right place.

    How you could use it

    If your app turns PDFs, scans or forms into structured data, this gives you an open starting point plus a recipe for adapting it. You could compare it against your current extraction step on a handful of your own messy documents before deciding to switch.

Worth knowing

  1. anthropics/claude-code v2.1.331

    Claude Code 2.1.331 added Code Mode in terminal sessions on Bedrock, Google Cloud, Foundry and AWS. It also added connection checks to claude doctor, the built-in command that diagnoses setup problems.

    Real-world example

    A developer at a company that only allows cloud-hosted models could now use Code Mode through their approved provider, and run claude doctor when requests mysteriously fail.

    How you could use it

    If you reach Claude through a cloud provider, try Code Mode in your terminal sessions. When something stops responding, run claude doctor first to rule out connection problems before debugging your own code.

Technique of the day

MCP authoring

An MCP server is a small program that gives an AI assistant new abilities, like looking up orders or adding a calendar event. You describe each ability as a tool with a name, a short description and the inputs it needs, then write the code that does the work. Any MCP-aware assistant can then call those tools. Writing your own is how you fill gaps that official servers leave open.

Try it

Ask Claude Code:
"Create a minimal MCP server in TypeScript with one tool, add_note, that takes a title and text and appends them to notes.txt. Include setup steps to connect it to Claude Code, and a quick way to test the tool."
Then ask the assistant to add a note and check the file.
